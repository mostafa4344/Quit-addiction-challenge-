# Quit Challenge (আসক্তি চ্যালেঞ্জ)

আসক্তি ছাড়ার জন্য একটা Android অ্যাপ। নিজেই চ্যালেঞ্জ ঠিক করুন: কতদিন বা কত ঘণ্টা আসক্তি থেকে দূরে থাকবেন। অ্যাপ টাইমার চালাবে, অনুপ্রেরণা দেবে, আর কোন প্রেশারে আপনি দুর্বল হন সেটা বিশ্লেষণ করে প্ল্যান সাজিয়ে দেবে।

## ফিচার

- **চ্যালেঞ্জ তৈরি:** নাম, আসক্তির ধরন (সোশ্যাল মিডিয়া, গেম, ধূমপান ইত্যাদি), লক্ষ্য দিন ও ঘণ্টায়, আর "কেন ছাড়তে চাই" কারণ।
- **লাইভ টাইমার ও প্রোগ্রেস:** সেকেন্ড ধরে কতক্ষণ টিকে আছেন, লক্ষ্যের কত শতাংশ পূরণ হলো।
- **মাইলস্টোন ব্যাজ:** ১ ঘণ্টা, ১ দিন, ৩ দিন, ১ সপ্তাহ, ২১ দিন, ১ মাস... এভাবে পর্যন্ত।
- **অনুপ্রেরণা:** প্রতিদিনের উক্তি আর প্রোগ্রেস অনুযায়ী মেসেজ।
- **ইচ্ছা লগ (⚡):** ইচ্ছা হলে তীব্রতা আর প্রেশার লগ করুন। সাথে সাথে টিপস আর আপনার নিজের কারণ দেখানো হবে।
- **ফেইল হলে নতুন শুরু:** কোন প্রেশারে হেরেছেন লিখে রাখুন। চ্যালেঞ্জ শূন্য থেকে আবার শুরু হবে, আগের চেষ্টার রেকর্ড থেকে যাবে।
- **লেভেল আপ:** লক্ষ্য পূরণ হলে পরের লেভেলে লক্ষ্য দ্বিগুণ হয়।
- **প্রেশার বিশ্লেষণ:** কোন প্রেশার (স্ট্রেস, একঘেয়েমি, একাকীত্ব ইত্যাদি) সবচেয়ে বেশি টানে, দিনের কোন সময়ে ঝুঁকি বেশি, সফলতার হার। এর ভিত্তিতে ব্যক্তিগত প্ল্যান।

- **অ্যাপ টাইম লিমিট চ্যালেঞ্জ:** Facebook, YouTube-এর মতো অ্যাপ বেছে দৈনিক সময়সীমা দিন। অ্যাপ নিজেই ব্যবহারের সময় মাপবে (Usage access, Digital Wellbeing-এর মতো)। লিমিটের ৮০% পার হলে ব্রেকের নোটিফিকেশন আসবে। লিমিট পার হলে চ্যালেঞ্জ ফেইল হয়ে আবার শুরু হবে, আর সতর্ক স্ক্রিন দেখাবে।
- **কিওয়ার্ড গার্ড:** Accessibility সার্ভিসের মাধ্যমে লিস্টের কোনো শব্দ টাইপ বা সার্চ করলে "You have tried to search … Are you sure you want to continue?" স্ক্রিন আসবে। লিস্ট নিজের মতো বদলানো যায়।
- **Protection ট্যাব:** সব পারমিশন এক জায়গা থেকে চালু করা যায়।

অ্যাপের ভাষা ইংরেজি। সব ডেটা শুধু ফোনেই থাকে। কোনো অ্যাকাউন্ট বা ইন্টারনেট লাগে না।

## APK ডাউনলোড

প্রতিবার কোড পুশ হলে GitHub Actions নিজে থেকেই APK বানায়।

1. রিপোর **Releases** অংশে **latest** খুলুন।
2. `QuitChallenge.apk` ফোনে ডাউনলোড করে ইনস্টল করুন। প্রথমবার "Unknown sources / অজানা উৎস থেকে ইনস্টল" অনুমতি দিতে হতে পারে।

## ডেভেলপারদের জন্য

- Kotlin + Jetpack Compose (Material 3), minSdk 26
- বিল্ড: `./gradlew assembleDebug`
- টেস্ট: `./gradlew testDebugUnitTest`
